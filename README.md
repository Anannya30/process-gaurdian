# OS Process Guardian

OS Process Guardian is a Linux process monitoring and anomaly detection
application implemented in C11 with GCC, Make, and ncurses.

## Repository Structure

- `include/` contains public headers and shared interfaces.
- `src/` contains the Guardian application modules.
- `tests/` contains module tests and controlled test programs.
- `logs/` contains the runtime event log.
- `docs/` is reserved for project documentation.

Implementation is pending. The authoritative requirements are documented
in `MASTER_SPEC.md`.
